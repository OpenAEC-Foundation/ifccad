# IFCCAD 2026.48.0 alpha

Native source alpha, 26 November 2026. Tag `v2026.48.0`.

## Changes since 2026.47.0

- Drawing-owned DWG/DXF/IFCCAD source descriptors with independent stable local
  source IDs and allocation history. Multiple placements and unused definitions
  are supported. Equal paths, names or fingerprints do not merge identities.
- URI-reference and search-filename locations retain their authored spelling.
  Core validation performs no filesystem/network IO. Missing sources are valid.
- Model XREF placements use O/X/Y, source base point and one positive uniform
  effective scale. Native Attach/Overlay is a per-relationship property; Attach
  is the omitted default. Source geometry stays external.
- Official Document #32 and Studio #3651 provide typed exchange, finite nested
  loading, overlay propagation, cycle diagnostics and source-save refresh.
  Cycle cuts and loaded graphics are session-only, preserving authored references
  through editing, undo/redo, native offline save and physical CAD readback.
- Explorer integration adopts the official merges and the grouped three-format
  example, owner-scoped source choice/reuse and current source diagnostics.

## File contract and limits

Profile 0.12.0 and CBOR mapping 12 replace published profile 0.11.0 / mapping 11.
Several accepted unpublished XREF slices share this revision. Old imports and
CBOR envelopes are not silently accepted as the new contract; no migration or
backward-compatibility guarantee is added. Zstd transport revision 1 is unchanged.
FingerprintGUID remains optional for DWG/DXF; no content hash or native source
UUID is invented. Source GUID observations do not silently replace stored metadata.

Native XREF ownership remains Model-only, rotation about Z and positive uniform
scale. Paper/local-block ownership, arbitrary 3D placement, mirroring and
nonuniform scale remain future work. Native Bind, remote fetching, complete
archives and automatic conversion of external DXF/IFCCAD sources for DWG/DXF
CAD delivery are not included. SHX and CTB/STB keep their existing records.
The current host XREF reader qualifies JSON/CBOR native sources, not Zstd sources.
An independently AutoCAD-authored known-GUID reference fixture remains an open
external qualification item, not a general interoperability certificate.

## Distribution and verification

Release assets contain only the native core source package, registry-only native
lockfile, schemas, conformance, examples and release documentation. No CAD runtime,
Studio executable, Explorer bundle, private checkout/configuration or cache is
part of the native source archive. Example drawing data does not bundle external
reference projects automatically. Explorer is built and deployed separately.

Final candidate checks and package/archive identities are recorded before
publication. Existing development/PR results do not substitute for the actual
release processor/host build or public deployment verification.
