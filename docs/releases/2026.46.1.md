# IFCCAD 2026.46.1 alpha

Native source alpha, 13 November 2026. Tag `v2026.46.1`.

- Adds native CAD tables with typed cells, merged ranges, styles and overrides.
  Cells can reference blocks and fields. The model stores formulas, data links,
  saved cell values and optional table graphics. Studio handles recalculation
  and refresh.
- Adds shared preservation for selected ModelSpace MLINE content. Several
  preserved roots can refer to one stored Document selection package.
  Studio retains blocked roots when editing and saving IFCX.
- Explorer uses the official Document and Studio integrations. It shows the
  backing package in the inspection graph and adds one parts-list table to the
  existing entity catalogue.

The file contract uses IFCX `ifcx_alpha`, profile `0.10.0`, CBOR mapping 10
and optional Zstd transport 1. Shared Document preservation uses envelope
revision 2. The previous published alpha used profile `0.8.0` and CBOR
mapping 8. Those files require their matching reader.

The native crate and source archive contain the IFCCAD core, schemas,
conformance cases, tests and examples. Explorer has a separate deployment.
