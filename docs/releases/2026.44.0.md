# IFCCAD 2026.44.0 alpha

**Native core source alpha — 27 October 2026.** Tag: `v2026.44.0`.
The GitHub prerelease contains the final source commit and SHA-256 checksums.

IFCCAD remains alpha. Later releases may not open these files, even weeks later.
There is no general backward-compatibility guarantee, retained-reader obligation
or mandatory automatic/manual migration. Keep original source drawings.

## Supported native contracts

- JSON/IFCX: `ifcx_alpha`, IFCCAD `profileVersion = 0.1.0`, experimental import
  `urn:example:ifccad:0.1.0`; offline profile resolution.
- Standalone IFCCAD-CBOR: mapping revision `1`.
- Optional native CBOR + Zstd: transport revision `1`, inner mapping `1`;
  core feature `ifccad-cbor-zstd`, disabled by default.

These are separate from software version `2026.44.0`. This first release fixes
the exact tagged contracts; earlier unpublished drafts carrying the same file
identifiers may differ and have no compatibility guarantee. No general IFCX
binary format or ZIP container is introduced.

## Included scope

Source for the core drawing model, strict validation, JSON/CBOR storage and
optional Zstd, with its schemas, core tests, examples and release documentation.
Current native coverage includes paths and widths, blocks, Model/Paper layouts,
appearance, line patterns, Text/MText, linear/aligned Dimensions with bounded
stored graphics, SOLID/TRACE, Hatch and workspace state. See the current
[converter coverage contract](https://github.com/OpenAEC-Foundation/ifccad/blob/v2026.44.0/crates/ifccad-convert/README.md) for exact
qualified CAD semantics and loss reporting in the separate repository workspace.

All active repository software manifests use the date scheme; this does not put
every workspace member into this release. File bytes and reader semantics are
unchanged by this release preparation. The native core package and its source
archive have a standalone normalized Cargo manifest, registry-only dependencies
and a core-only lockfile. Neither includes ifccad-convert, the CAD companions,
acadrust/opencadcodec, opencaddocument, viewer/browser or Explorer. No crates.io
publication, prebuilt binaries, host deployment or Studio integration is included.
Use the attached native source archive or `.crate` for this release. GitHub's
automatic source snapshots contain the whole repository, including unreleased
workspace companions; those companions are outside the released native scope.

## Known boundaries and breaks

No compatibility with historical OCDraw or arbitrary earlier alpha drafts.
Only linear/aligned Dimension definitions are native today; other kinds remain
future work. Stored graphics are bounded, not a dimension generator or a visual
equivalence guarantee. Font contours, full annotation display and evaluated
Hatch rendering remain unassessed. Unsupported CAD content is diagnosed or
rejected according to the conversion contract; no arbitrary-file lossless claim.

CAD conversion support is separate from this native release. The workspace's
codec and its known standalone limitations are verification context, not released
core dependencies. The future main conversion route belongs to opencaddocument;
changing Explorer or adding direct Studio CBOR/Zstd opening is outside this release.
