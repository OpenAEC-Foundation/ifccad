# IFCCAD 2026.45.2 alpha

**Native core source alpha — 6 November 2026.** Tag: `v2026.45.2`.

Block attributes now retain ATTDEF definitions and ordered INSERT-owned ATTRIB
values, with separate outer Text and active embedded MText. This includes empty
MText, visibility and constant/preset/verify flags, position locks, signed
thickness, annotation contexts, explicit definition references and the selected
stored Filename/Line-Length field graphs and caches. File IO does not evaluate
fields or synchronize instances. MINSERT and dynamic blocks remain deferred.

## File contracts and compatibility

- IFCX syntax: `ifcx_alpha`; native profile **0.6.0**, import
  `urn:example:ifccad:0.6.0`.
- Standalone CBOR: mapping revision **6**.
- Optional CBOR + Zstd: transport revision **1**, inner mapping **6**.

The previous release 2026.45.1 used profile 0.5.0 / CBOR5. Current readers reject
unsupported identifiers; historical readers and migrations are not included.
Earlier released collections and tags remain immutable.

## Shared exchange and Explorer

Official Document PR [#12](https://github.com/HakanSeven12/opencaddocument/pull/12)
merged at `e7b79f163e1a4e847f3f98109021a5671683b342`, the exact qualified head.
Its explicit codec dependency is the published support revision
`0f20af02a1d6be744272e64dd505e8c8933c8772` in the BjornFidder/opencadcodec fork;
that thickness fix is not presented as merged upstream. The embedded host uses
Studio `81bbb05e`, kernel `fc20d605` and compatible native model `21660ce1`.
The bounded host patch is retained under `format-explorer/ocs-inputs`, alongside
its editing/ATTSYNC smoke sources. Production dependency checks reject duplicate
models and local development overrides are absent from the release pins.

The existing catalogue block now has Text/MText attributes; a separate grouped
attribute gallery covers flags, stored fields and Paper titleblocks. Inspector
child selection targets its owning INSERT. Review includes the accepted gallery
and sample_AC1032 roundtrip. Strict physical AC1032 DWG and ASCII/binary DXF
readback diagnoses absent physical ATTDEF binding, normalized outer MText
fallbacks and unavailable legacy Field.format storage. No tag-based rebinding or
whole-drawing fidelity claim is made. Generic secondary links have no qualified
CAD transport. See [block attributes](../block-attributes.md).

Bounded OCS checks cover value edits, grips, undo/redo and strict save/reopen.
The existing ATTSYNC operation moves definition positions and adds new attributes
while retaining distinct instance values; it is an editor operation, not an IO
side effect. General editor behavior is outside this qualification.

## Native artifacts and delivery

The attached `.crate` and deterministic source archive contain only the native
core, schemas, tests, examples and documentation, with registry-only dependencies
and an isolated lockfile. Document, CAD runtimes, viewer/browser, Explorer and
local patches are excluded. There is no crates.io publication or prebuilt native
binary. GitHub's automatic repository snapshots have broader scope.

Verification covers the final workspace candidate, optional Zstd, release tools
and frontend, plus isolated native packaging and source-archive checks. Accepted
physical roundtrip evidence remains separate from whole-file fidelity. No size
benchmark or corpus sweep was run. Explorer deployment uses its separate CI and
public smoke check; publication of native artifacts alone does not prove a live
Explorer update. `release-manifest.json` records exact revisions, verification
and artifact hashes; `SHA256SUMS` covers the uploaded assets.
