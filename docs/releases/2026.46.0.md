# IFCCAD 2026.46.0 alpha

Native source alpha, 11 November 2026. Tag `v2026.46.0`.

- Adds classic Leader, MultiLeader and Tolerance, with typed owned parts,
  annotation references and supplied graphics.
- Adds standalone splines, Hatch spline edges and Paper viewport spline clips.
  The Document route keeps control and fit data where the target can carry them.
  DWG output diagnoses omitted fit data in mixed definitions. Strict spline
  export refuses a target that would lose that data.
- Adds compact Leader, MultiLeader and open cubic spline samples to the Explorer
  entity catalogue. The Leader sample includes a Tolerance annotation.
  Explorer includes the merged Studio correction for drawing compact periodic
  splines. The build pins Document `b7f02ad6`, acadrust
  `acad0df2` and Studio `668ae67b`. The codec pin includes the rational-weight
  DXF correction.

The file contract uses IFCX `ifcx_alpha`, profile `0.8.0`, CBOR mapping 8 and
optional Zstd transport 1. The previous published alpha used profile `0.6.0`
and CBOR mapping 6. Opening those files requires their matching reader.

The native package and source archive contain the core, schemas, tests and
examples. Explorer ships through its separate deployment workflow. Physical
exchange coverage depends on the CAD version and entity. The physical payload
for owned MultiLeader tolerance content remains open.
