# IFCCAD 2026.47.0 alpha

Native source alpha, 18 November 2026. Tag v2026.47.0.

- Stores CTB and STB references as external plot-style sources. A layout can retain
  its table reference and an optional SHA-256 fingerprint, including when plot
  styles are disabled. The drawing stores its color-dependent or named mode.
- Stores named STB assignments on layers and entities and retains the explicit
  ByBlock and Normal choices. CTB output uses the original ACI when an IFCCAD
  RGB fallback changes, with a conversion diagnostic.
- The shared Document route retains table names when writing DXF and DWG. It
  reports the loss of a known fingerprint and rejects export when two different
  table fingerprints share one filename. Keep the external CTB or STB files with
  the drawings for plotting.
- Explorer uses the merged Document and Studio revisions. The CTB and STB
  round trips through Explorer retained the tested plot assignments, and Studio
  reproduced the expected PDF colors and lineweights from the exported files.

The file contract uses IFCX ifcx_alpha, profile 0.11.0, CBOR mapping 11 and
optional Zstd transport 1. The previous alpha used profile 0.10.0 and CBOR
mapping 10. Use the matching reader for files from that alpha. In profile
0.11.0, layout plot-style table references point to external source records.

The native crate and source archive contain the IFCCAD core, schemas,
conformance cases, tests and examples. Explorer follows its own deployment.
