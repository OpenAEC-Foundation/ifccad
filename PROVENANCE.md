# Provenance

IFCCAD's model-first Python reference, format experiments, schemas, and
cross-language conformance work were developed in the
[IFCCAD prototype](https://github.com/OpenAEC-Foundation/ifccad-prototype). The
reference snapshot at the Rust repository transition was
`2404e997175eb8110e177856dbc61db1d873be96`; later prototype commits remain
traceable in that repository.

The initial Rust implementation was developed temporarily in the
[acadifc](https://github.com/OpenAEC-Foundation/acadifc) migration-source
repository. The clean import in this repository was created on 2026-08-10
from acadifc commit `b0ba408f07e21fc540bff30b7430fdc4297524bf`.

Relevant Rust development is recorded in acadifc pull requests
[#2](https://github.com/OpenAEC-Foundation/acadifc/pull/2),
[#3](https://github.com/OpenAEC-Foundation/acadifc/pull/3),
[#4](https://github.com/OpenAEC-Foundation/acadifc/pull/4),
[#8](https://github.com/OpenAEC-Foundation/acadifc/pull/8),
[#9](https://github.com/OpenAEC-Foundation/acadifc/pull/9),
[#10](https://github.com/OpenAEC-Foundation/acadifc/pull/10), and
[#11](https://github.com/OpenAEC-Foundation/acadifc/pull/11).

The acadifc repository began from acadrust history. This repository does not
import that Git history or the DWG/DXF/ACIS implementation. Those remain
attributable in their existing repositories. The licence and source
provenance bundled inside each conformance collection remain authoritative
for those assets.
